# Mirotokhome — для разработчика

Техническое описание проекта. Правила, архитектура и журнал решений — в
`AGENTS.md`; здесь — как устроено и как проверять.

## Стек

- **Godot 4.7**, GDScript 2.0, `GL Compatibility`.
- Разрешение 1280×800, `canvas_items` stretch, равномерный масштаб UI.
- Сетка карты 32×32, `TileMapLayer`, uint16-кодировка тайла.
- Единственный autoload — `WorldBus` (SIM-мир).
- Глобальные классы: `Game` (бой, статика), `SoundDB`, `SpellDB`, `ItemDB`,
  `UnitDB`, `StructureDB`, `CraftDB`, `QuestDB`, `SaveSystem`, `ModLoader`,
  `ContentRules`, `MapGenerator`, `Loc`, `UiKit`, `UiTheme`.

## Что реализовано

### Мир и генерация

- `MapGenerator` (`scripts/world/map_generator.gd`): Voronoi-биомы, города
  (овалы из дорог), MST-дороги через A* с ценой по terrain, горы/вода поверх
  дорог без их перетирания, псевдо-высоты.
- 7 terrain-типов: трава, горы, вода, дорога, почва, песок, грязь. Горы и вода
  непроходимы (летающие юниты с `fly_z` их обходят).
- Рендер террейна — `BlendMesh` (`alm_map.gd`) + шейдер: `u_primary`,
  `u_secondary`, `u_border`, полоса текстуры на биом. `transition_db.json` —
  справочные данные по переходам, на картинку больше не влияет.
- Чанки террейна 16×16 по камере; туман войны (`fog_of_war.gd`) с маской
  0/1/2 и шейдером мягких кромок; состояние фога — в сейве.
- Порталы между зонами: сетка 12 секторов (4×3), парные порталы по границам,
  подтверждение перехода, автосейв.
- Редактор карт (`scenes/map_editor.tscn`): terrain, структуры, пропы, НПЦ,
  спавн, порталы, высоты/препятствия, undo; полная запись `.alm` + sidecar-ов
  (`.spawn/.portal/.structures/.npcs/.meta.json`), валидатор карты.

### Бой

- **Единая точка урона** — `Game.deal_damage(target, dmg, kind, sphere, attacker)`
  плюс `deal_damage_area`, `is_miss`, `shield_reduce`, `apply_shield`: вся
  математика (попадание, броня, защита стихии, щиты) в одном месте.
- Герой: ближний бой, мгновенная магия по цепочке сфер, книга магии (24
  каноничных слота + выученное сверх), свитки у воина.
- Враги: FSM (idle → погоня → атака → побег), летающие, тиры Серых.
- Наёмники: приказы (след/стоп/охрана/атака), лимит отряда, лояльность.
- Снаряды, AoE, наземные зоны, стены, ауры, статус-эффекты
  (`spell_zone.gd`, `spell_wall.gd`, `status_effects.gd`).
- **Тактическая пауза** (пробел): мир не тикает, магия и хоткеи блокируются.

### Мир, фракции, события

- `scripts/world/`: `WorldState` (день, угроза, отношения, журнал),
  `WorldBus` (autoload), `WorldSim` (дни), `sim_runner.gd` (headless на 100 дней).
- 5 фракций: Альянс Света, Орды Огня, Пожинатели, Круг Друидов, Серые (всегда
  враги). Репутация → качество наёмников и тир ассортимента.
- Города: здания по расе, стражи, капитан, жители; интерьеры Лавка, Таверна,
  Мастерская (кузнец/портной), Алхимия, Школа, Великий маг.
- Форпосты: 3 лагеря на карту, стража нейтральна при репутации ≥ 0 и враждебна
  после удара, захват даёт чертежи фракции.
- События-стычки монстров (`event_system.gd`) с маркерами миникарты.
- Задания: шаблоны в `assets/quests/quest_db.json` (`QuestDB`, `quest_system.gd`),
  журнал по W.

### Предметы, крафт, торговля

- `item_db.json` — экипировка, зелья, свитки, книги, травы; сломанные вещи
  (`assets/items/broken/` — иконка с перечёркиванием).
- Мастерская: разбор/переработка, рецепты (кузнец, портной, мастер), навыки
  ремёсел с кривой роста.
- Алхимия: рецепты в данных, атомарный расход ингредиентов; травы на карте с
  регенерацией.
- Лавка: зелья, свитки, книги (включая книги школ — так открывается модовая
  школа магии), рецепты, фракционные чертежи. Экипировку лавка не продаёт.

### Моды

- `ModLoader`: папки `res://mods` и `user://mods`, `mod.json`, записи
  `{into, key, op, extends}`, операции `add/patch/remove/append`, порядок
  `depends_on → load_after → priority → id`, громкая диагностика конфликтов.
- `ContentRules`: правила контента в `assets/config/content_rules.json` (сферы,
  типы/слоты предметов, расы, папки зданий, лут, таверна, виды Серых).
- `ModsPanel` в главном меню: превью, включение, ручной порядок, диагностика.
- Валидатор `tests/mod_validate.gd` проверяет папку без запуска игры.
- Документация: `docs/mods.md`, `docs/mods-first.md`, примеры в
  `docs/mods/examples/`.

### Сохранения, звук, освещение

- `SaveSystem` v2: 6 слотов + автосейв, атомарная запись (`.tmp` → `.bak`),
  профиль модов в сейве, отряд и хотбар.
- `SoundDB` (именованные ключи, шины Music/SFX/UI/Voice/Ambient), `MusicDB`
  (непрерывный плейлист с кроссфейдом).
- Свет: три слоя, `CanvasModulate` + `Light2D` + `LightOccluder2D`, glow через
  `WorldEnvironment`, пост-обработка экранным шейдером.

### Арт: 3D-модель → спрайты героя

- Моделлер присылает `.blend` (и `.glb` запасным) с четырьмя действиями
  `idle`/`walk`/`attack`/`die`; бриф для него — `docs/3d-model-brief.md`.
- `tests/render_3d_frames.py` (Blender 4.2/5.2 + Python/Pillow) рендерит
  12 кадров 64×64 с ортокамеры три четверти, нормализует масштаб по `idle` и
  пивот по origin модели, пишет `sprites-001..012.png`, `_entry.json` и
  контактный лист.
- Исходники 3D в git не идут: `import/3d_src/`, `*.blend`, `*.blend1` —
  в `.gitignore`.

## Проверки

```bash
# парсинг всех скриптов: пусто = OK
godot --headless --path . --quit 2>&1 | grep -E 'SCRIPT ERROR|Parse Error'

# SIM-мир на 100 дней
godot --headless --path . --script res://scripts/world/sim_runner.gd

# точечный тест
godot --headless --path . --script res://tests/scroll_book_smoke.gd
```

Перед первым прогоном в свежем клоне нужен импорт ассетов:
`godot --headless --path . --import` (долго: сотни изображений).

`ERROR: N resources still in use at exit` — безобидный хвост движка, не ошибка.

Полный список тестов и что каждый сторожит — `AGENTS.md`, §9.

## Конвенции (кратко)

- Отступы — табы; типизированный GDScript; узлы через `@onready` и `%Node`.
- **Комментарии в коде и сообщения коммитов — только английский.**
- Тексты для игрока — русский, через `Loc`/`assets/locale`.
- Данные — в JSON/`Resource`, не в хардкоде; новый тип контента — через
  `ContentRules`.
- Ветки `feature/agent-<task>`, коммит только после ручной проверки в игре.

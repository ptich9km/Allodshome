# Описание атласа оружия

## 1. Общая информация

-   **Файл изображения:**
    `a_detailed_grid_style_game_ui_sprite_sheet_icon.png`
-   **Размер изображения:** `1312 × 1199 px`
-   **Начало координат:** левый верхний угол изображения --- `(0, 0)`
-   **Ось X:** слева направо
-   **Ось Y:** сверху вниз
-   **Размер игровой иконки:** `80 × 80 px`
-   На листе показаны **15 типов предметов**, каждый в **4 вариантах
    качества**:
    1.  Дешевая
    2.  Обычная
    3.  Хорошая
    4.  Элитная

> **Важно:** изображение является демонстрационным атласом с панелями и
> подписями. Координаты ниже относятся к этому PNG, а не являются уже
> готовой разметкой 80×80 для импорта в игру.

# 7. Уровни качества

Во всех блоках используется одинаковая логика:

  -----------------------------------------------------------------------
  Уровень                             Визуальная идея
  ----------------------------------- -----------------------------------
  **Дешевая**                         Грубое железо, простая древесина,
                                      минимум украшений

  **Обычная**                         Более качественный металл,
                                      аккуратная рукоять, улучшенная
                                      отделка

  **Хорошая**                         Благородные металлы, декоративные
                                      элементы, улучшенная форма

  **Элитная**                         Золото/синий металл, драгоценные
                                      детали, сложный орнамент
  -----------------------------------------------------------------------

# 8. Важное замечание для игровой сетки 80×80

Если предметы должны непосредственно импортироваться в игру как **80×80
px**, текущий демонстрационный лист лучше не резать по границам панелей.

Для игрового атласа рекомендуется сделать отдельный PNG:

``` text
80 × 80 px — одна текстура
Прозрачный фон
Только предмет
Без названия
Без рамки
Без текста
Без фоновой панели
```

То есть каждый предмет должен занимать отдельную ячейку:

``` text
┌────────┐
│        │
│  МЕЧ   │  80×80
│        │
└────────┘
```

Для 15 типов × 4 качества потребуется:

**15 × 4 = 60 отдельных текстур 80×80 px.**

Итого при размещении в один горизонтальный/вертикальный атлас:

-   `60 × 80 = 4800 px` по одной стороне при линейном размещении;
-   либо, например, сетка `10 × 6` → **800 × 480 px**;
-   либо `8 × 8` с двумя пустыми ячейками → **640 × 640 px**.

Для игры я бы использовал **8×8 атлас 640×640 px**, где каждая ячейка
строго `80×80 px`, а пустые ячейки остаются прозрачными.

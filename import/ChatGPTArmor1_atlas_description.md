# Описание атласа одежды и брони

## 1. Общие параметры изображения

- **Файл:** `a_clean_high_resolution_game_asset_atlas_ui_spr.png`
- **Размер PNG:** `1312 × 1199 px`
- **Начало координат:** `(0, 0)` — левый верхний угол изображения.
- **Ось X:** слева направо.
- **Ось Y:** сверху вниз.
- **Игровой размер одной текстуры:** `80 × 80 px`.
- **Количество наборов:** `3`.
- **Типов элементов в каждом наборе:** `9`.
- **Вариантов качества каждого элемента:** `4`.
- **Всего игровых текстур:** `3 × 9 × 4 = 108`.

> Координаты ниже описывают **положение ячеек на данном демонстрационном PNG**. Они не означают, что фактический размер каждой ячейки на картинке равен 80×80 px. В игре каждый отдельный предмет должен экспортироваться как самостоятельная текстура 80×80 px с прозрачным фоном.

# 10. Требования к отдельной игровой текстуре

Каждый из 108 предметов должен экспортироваться как:

```text
Размер: 80 × 80 px
Формат: PNG
Фон: полностью прозрачный
Базовый слой: отсутствует
Предмет: только один
Текст: отсутствует
Рамка: отсутствует
UI: отсутствует
```

Например:

```text
80×80
┌────────────────┐
│                │
│      ШЛЕМ      │
│                │
└────────────────┘
```

Сам предмет должен быть центрирован внутри 80×80, но **не должен иметь искусственного фонового квадрата**.

# 11. Визуальная прогрессия качества

Для всех трёх наборов рекомендуется сохранять одну и ту же логику улучшения:

### 1 — Дешевая

- простые материалы;
- обычная кожа;
- грубый металл;
- минимум украшений;
- небольшая детализация.

### 2 — Обычная

- более качественная кожа;
- лучше обработанный металл;
- аккуратные швы;
- небольшие декоративные элементы.

### 3 — Хорошая

- улучшенный металл;
- дорогая кожа/ткань;
- декоративные вставки;
- драгоценные камни или цветные элементы.

### 4 — Элитная

- сложная конструкция;
- золото/серебро;
- драгоценные камни;
- орнаменты;
- заметные декоративные элементы;
- наиболее высокая детализация.

---

# 12. Важное правило для игры

**Не смешивать наборы.**

Лёгкая броня должна визуально оставаться лёгкой даже на элитном уровне.

Тяжёлая броня должна выглядеть массивной на всех четырёх уровнях.

Магическая одежда должна сохранять тканевую/магическую основу, а качество повышаться за счёт:

- вышивки;
- рун;
- драгоценных камней;
- магического свечения;
- более дорогих тканей;
- сложных орнаментов.

Таким образом, игрок должен понимать тип предмета даже без названия.

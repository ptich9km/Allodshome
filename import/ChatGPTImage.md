# Описание текстурного атласа

## Общая информация

* **Размер изображения:** 1536 × 1024 px
* **Система координат:** `(0, 0)` — верхний левый угол
* **Количество биомов:** 7
* **Вариаций каждого биома:** 6
* **Всего базовых текстур:** 42
* **Размер игровой клетки:** 32 × 32 px
* **Формат:** тайловый атлас
* **Назначение:** базовые бесшовные текстуры для карты игры

# Логическая адресация

Для использования в игре удобно считать каждую текстуру как:

```text
biome[row][column]
```

или:

```text
biome[variation][type]
```

где:

```text
type:
0 = desert
1 = mountain
2 = mud
3 = water
4 = soil
5 = grass
6 = road
```

и:

```text
variation:
0 = variation_1
1 = variation_2
2 = variation_3
3 = variation_4
4 = variation_5
5 = variation_6
```

Примеры:

```text
[0][0] = Пустыня #1
[0][1] = Гора #1
[0][2] = Грязь #1
[0][3] = Вода #1
[0][4] = Почва #1
[0][5] = Трава #1
[0][6] = Дорога #1

[5][0] = Пустыня #6
[5][1] = Гора #6
[5][2] = Грязь #6
[5][3] = Вода #6
[5][4] = Почва #6
[5][5] = Трава #6
[5][6] = Дорога #6
```

# Соответствие игровой сетке 32×32

Игровое поле использует клетки:

```text
32 × 32 px
```

Поэтому каждая базовая текстура должна рассматриваться как **один игровой тайл**, а не как произвольная картинка.

Для конечного игрового атласа рекомендуется привести каждую текстуру к:

```text
32 × 32 px
```

Таким образом получится:

```text
7 биомов × 6 вариаций = 42 тайла

42 × 32 × 32 px
```

Удобная структура итогового атласа:

```text
              0       1       2       3       4       5       6
          ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
row 0     │ D-01  │ M-01  │ Mu-01 │ W-01  │ S-01  │ G-01  │ R-01  │
          ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
row 1     │ D-02  │ M-02  │ Mu-02 │ W-02  │ S-02  │ G-02  │ R-02  │
          ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
row 2     │ D-03  │ M-03  │ Mu-03 │ W-03  │ S-03  │ G-03  │ R-03  │
          ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
row 3     │ D-04  │ M-04  │ Mu-04 │ W-04  │ S-04  │ G-04  │ R-04  │
          ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
row 4     │ D-05  │ M-05  │ Mu-05 │ W-05  │ S-05  │ G-05  │ R-05  │
          ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
row 5     │ D-06  │ M-06  │ Mu-06 │ W-06  │ S-06  │ G-06  │ R-06  │
```

## Обозначения

```text
D  = Desert / Пустыня
M  = Mountain / Гора
Mu = Mud / Грязь
W  = Water / Вода
S  = Soil / Почва
G  = Grass / Трава
R  = Road / Дорога
```

# Важное требование к тайлам

Все 6 вариаций одного биома должны:

1. иметь одинаковую базовую цветовую палитру;
2. иметь одинаковый масштаб деталей;
3. стыковаться по левому и правому краю;
4. стыковаться по верхнему и нижнему краю;
5. не создавать видимых швов при повторении;
6. отличаться деталями, но не типом поверхности;
7. сохранять одинаковую освещённость;
8. не иметь рамок или чёрных разделителей внутри игрового тайла.

Например, все варианты воды должны выглядеть как одна непрерывная поверхность:

```text
┌──────┬──────┬──────┬──────┐
│ W01  │ W03  │ W02  │ W06  │
├──────┼──────┼──────┼──────┤
│ W04  │ W01  │ W05  │ W03  │
├──────┼──────┼──────┼──────┤
│ W06  │ W02  │ W04  │ W01  │
└──────┴──────┴──────┴──────┘
```

При этом границы между тайлами не должны быть заметны.

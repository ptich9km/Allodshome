# Описание атласа оружия

## 1. Общая информация

Атлас содержит 13 типов оружия и 4 варианта качества каждого типа.

- **Фактический размер изображения:** 1536 × 1024 px
- **Игровой размер одной текстуры:** 80 × 80 px
- **Количество типов оружия:** 13
- **Вариаций каждого оружия:** 4
- **Всего игровых текстур:** 52
- **Качество:** дешёвая, обычная, хорошая, элитная
- **Базовый слой:** отсутствует
- **Начало координат:** `(0, 0)` — верхний левый угол
- **X увеличивается:** вправо
- **Y увеличивается:** вниз

> Важно: верхняя часть изображения является демонстрационным атласом. Она не является пиксель-в-пиксель атласом 80×80. Поэтому ниже отдельно приведены логические координаты 80×80 для игры и приблизительные координаты областей на самой картинке 1536×1024.

# 3. Порядок качества

Каждая колонка содержит четыре варианта сверху вниз:

| Индекс | Качество | ID |
|---:|---|---|
| 0 | Дешёвая | `cheap` |
| 1 | Обычная | `common` |
| 2 | Хорошая | `good` |
| 3 | Элитная | `elite` |

Таким образом:

```text
row 0 = cheap
row 1 = common
row 2 = good
row 3 = elite
```

# 4. Логическая сетка игры 80×80

Если каждое оружие хранится как отдельная текстура размером 80×80 px, логический атлас имеет размер:

```text
13 × 80 = 1040 px
4 × 80  = 320 px

Итого: 1040 × 320 px
```

Схема:

```text
             X →
        0      1      2      3      4      5      ...    12
      ┌──────┬──────┬──────┬──────┬──────┬──────┬──────────────┐
  0   │Кинжал│1H меч │Сабля │2H меч │1H топ │2H топ │ ... │Щит│ Дешёвая
      ├──────┼──────┼──────┼──────┼──────┼──────┼──────────────┤
  1   │Кинжал│1H меч │Сабля │2H меч │1H топ │2H топ │ ... │Щит│ Обычная
      ├──────┼──────┼──────┼──────┼──────┼──────┼──────────────┤
  2   │Кинжал│1H меч │Сабля │2H меч │1H топ │2H топ │ ... │Щит│ Хорошая
      ├──────┼──────┼──────┼──────┼──────┼──────┼──────────────┤
  3   │Кинжал│1H меч │Сабля │2H меч │1H топ │2H топ │ ... │Щит│ Элитная
      └──────┴──────┴──────┴──────┴──────┴──────┴──────────────┘
  Y ↓
```

# 5. Формула координат

Для оружия с индексом `weapon` и качеством `quality`:

```text
x = weapon × 80
y = quality × 80

width  = 80
height = 80
```

Например:

```text
Сабля = weapon 2
Хорошая = quality 2

x = 2 × 80 = 160
y = 2 × 80 = 160
```

Область:

```text
x = 160..239
y = 160..239
```

# 7. Диапазоны координат

Для удобства можно считать диапазоны полуоткрытыми:

```text
[x, y, x + 80, y + 80)
```

Например:

```text
Кинжал / Дешёвый:
x = 0
y = 0
width = 80
height = 80

Кинжал / Элитный:
x = 0
y = 240
width = 80
height = 80

Щит / Элитный:
x = 960
y = 240
width = 80
height = 80
```

# 8. Координаты областей на фактической картинке

Фактическое изображение имеет размер **1536×1024 px**.

В верхней части расположен визуальный атлас. В нём слева находится отдельная колонка с названиями качества, поэтому первая игровая колонка начинается примерно с `x ≈ 69 px`.

Приблизительные границы 13 колонок на самой картинке:

| Индекс | Оружие | X начала | X конца |
|---:|---|---:|---:|
| 0 | Кинжал | 69 | 186 |
| 1 | Одноручный меч | 187 | 304 |
| 2 | Сабля | 305 | 422 |
| 3 | Двуручный меч | 423 | 540 |
| 4 | Одноручный топор | 541 | 658 |
| 5 | Двуручный топор | 659 | 776 |
| 6 | Одноручная булава | 777 | 894 |
| 7 | Двуручная булава | 895 | 1012 |
| 8 | Одноручное копьё | 1013 | 1130 |
| 9 | Двуручное копьё | 1131 | 1248 |
| 10 | Лук | 1249 | 1366 |
| 11 | Арбалет | 1367 | 1484 |

Из-за рамок, подписей и декоративных линий эти координаты являются координатами **визуальных ячеек на демонстрационном изображении**, а не координатами готовых игровых PNG.

# 10. Приблизительная координата конкретной текстуры

Например, **Сабля — Хорошая**:

```text
weapon = 2
quality = 2
```

Логические координаты игрового атласа:

```text
x = 2 × 80 = 160
y = 2 × 80 = 160

width  = 80
height = 80
```

На демонстрационной картинке она находится примерно здесь:

```text
X: 305..422
Y: 284..387
```

# 13. Важное требование к прозрачности

Оружие не должно иметь непрозрачного базового слоя.

Правильно:

```text
┌────────────────────┐
│        прозрачный  │
│          /         │
│       /██          │
│     /████          │
│       ██           │
│       ██           │
│                    │
│    прозрачный      │
└────────────────────┘
```

Неправильно:

```text
┌────────────────────┐
│████████████████████│
│████████████████████│
│██████  ОРУЖИЕ █████│
│████████████████████│
│████████████████████│
└────────────────────┘
```

Фон вокруг оружия должен быть **полностью прозрачным (RGBA alpha = 0)**.

# 14. Итоговая структура данных

Удобно идентифицировать каждую текстуру двумя индексами:

```text
weapon_id
quality_id
```

Например:

```json
{
  "weapon_id": "saber",
  "quality_id": "good",
  "atlas_x": 160,
  "atlas_y": 160,
  "width": 80,
  "height": 80
}
```

Полный список quality:

```text
0 = cheap
1 = common
2 = good
3 = elite
```

Формула:

```text
atlas_x = weapon_index × 80
atlas_y = quality_index × 80
```

Итоговый игровой атлас:

```text
1040 × 320 px
```

с сеткой:

```text
13 колонок × 4 строки
```

# Changelog

Все изменения проекта Allods Home (Godot версия) документируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/).

## [0.2.0] — 2026-09-09

### Added
- Миникарта в правом верхнем углу (зелёная трава, серые стены, синий игрок, красные враги)
- Панель действий: Следовать/Атаковать/Охранять с подсветкой активного режима
- Портрет персонажа в правой панели
- Панель характеристик: сила, ловкость, интеллект, выносливость, дух, урон, броня, защита, опыт, скорость
- 4 новых врага: летучая мышь (20 HP), орк тир2 (70 HP), людоед (100 HP), зомби (80 HP)
- NPC-тролль (80 HP)
- Панель заклинаний 2×12 (24 иконки) из скриншота Allods 2
- Toggle панелей: I — инвентарь, B — заклинания
- Лут-мешки после убийства врагов (3 размера: малый/средний/большой)
- 4 типа лута: золото, зелье HP, зелье маны, руда
- Рестарт сцены по Ctrl+R при смерти

### Changed
- HP/Mana бары над головами персонажей (не дублируются внизу)
- Инвентарь: пустые слоты 10×4 (без стартовых предметов)
- Спрайты врагов: чёрный фон заменён на прозрачность
- Окно увеличено до 1280×800

### Fixed
- Minimap: tilemap находился через группу "tilemap"
- ActionPanel сдвинута ниже миникарты (offset_top=205)
- Health bars подняты выше (position -65)
- Удалены все debug print сообщения
- Ошибка freed object при смерти игрока
- Целочисленное деление в расчёте цветов

## [0.1.0] — 2026-09-08

### Added
- Изометрическая карта 17x17 (травяной остров со стенами)
- Персонаж (воин) с click-to-move и click-to-attack
- 3 врага: 2 орка + 1 слизень с AI (idle/chase/attack/flee)
- 3 заклинания: Fireball (1), Heal (2), Lightning (3)
- HP/Mana бары игрока
- HP бары врагов
- Тактическая пауза (пробел)
- UI панель заклинаний
- TileSet с изометрическими тайлами (трава, стена)

### Changed
- Миграция с Unity C# на Godot 4 GDScript
- Упрощённая архитектура: ~300 строк кода вместо 600+

### Fixed
- Удалены лишние ExtResource для тайлов в main.tscn
- Регенерированы tile_grass.png и tile_wall.png
- Исправлены parent пути UI нод в main.tscn
- Удалены все предупреждения GDScript

# Changelog

Все изменения проекта Allods Home (Godot версия) документируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/).

## [0.13.11] — 2026-09-17

### Changed (UI, по мотивам UnityAllods)
- **Нижняя панель (магия/инвентарь) центрируется по горизонтали** для любого
  размера окна и прижимается к низу; при открытой только магии панель
  сужается до 480px (нет «чёрного прямоугольника» справа).
- **Инвентарь — один ряд** (горизонтальный скролл) на всю ширину панели,
  без второго ряда текстур снизу.
- **Счётчик количества** предметов в правом верхнем углу слота (стак/деньги),
  как у разработчиков (в их `ItemView` — `item.Count` и число в углу).

## [0.13.10] — 2026-09-17

### Fixed
- **Клики по интерфейсу больше не двигают героя**: клик по книге заклинаний,
  инвентарю и любым панелям/кнопкам UI игнорируется игровым обработчиком
  (`ui.is_pointer_over_ui` — проверка попадания с учётом видимости панели и
  всей цепочки родителей). Герой не «бежит» при выборе магии/предметов.
- Дополнительно: фикс «застревания» на склонах — путь строится от ближайшей
  проходимой клетки, порог застревания 20 кадров, подъём мягче (0.45).

## [0.13.9] — 2026-09-17

### Changed / Added
- **Ручная разметка проходимости в редакторе** — категория «Нельзя пройти»
  (инструмент 4): клик отмечает/снимает клетку (красный полупрозрачный маркер);
  сохраняется в JSON-карте (`"nowalk"`) и для .alm в sidecar
  `"<карта>.nowalk.json"`. В игре разметка имеет **приоритет** над автоматикой.
- **Проходимость по опыту/данным разработчиков**: ГОРЫ и холмы (tile2) —
  **проходимы** (медленнее ×0.75; у UnityAllods CostMountain=16 — дорого, но не
  блок), вода (tile3) и спец-барьеры — непроходимы, дороги ×1.4.
- **Погоня монстров с обходом препятствий** (pathfinding, перепланировка 0.7 с) и
  **без «побега»** (can_flee=false): враги идут к игроку и дерутся до конца,
  а не «пробегают мимо».
- **Подсказка координат**: «Тайл мыши: …», «Проход: да/НЕТ» и «Занято:
  <причина>» (вода / дерево-камень / здание / запрет разметки).

### Verified (headless)
- Компиляция чистая; полная сцена без ошибок.

## [0.13.8] — 2026-09-17

### Changed / Fixed
- **Выход из магазина/таверны/школы**: герой появляется на **проходимой** клетке
  (спиральный поиск, если исходная точка занята) и движение при входе
  останавливается — не «упирается в здание», не убегает по старой цели.
- **Вход в здание по подходу**: клик по магазину/таверне/школе издалека больше не
  открывает панель мгновенно — герой идёт к **двери** (проходимая клетка у южного
  края здания) и «входит» (панель) при близости.
- **Подсветка цели**: красное кольцо (`SelectRing`) под врагом — при наведении
  курсора и при атаке (текущая цель), чтобы было видно, кого выделили.
- **Лут-мешочек** вместо жёлтого круга: нарисован аккуратный мешочек с завязкой
  и золотым узелком.

### Verified (headless)
- Полная сцена без ошибок.

## [0.13.7] — 2026-09-17

## [0.13.5] — 2026-09-17

### Changed
- **Бой без «льда» и «битья в пустоту»**:
  - юниты больше не сталкиваются физически (`collision_mask = 0` у героя,

  - герой, если враг убежал из радиуса атаки, **возвращается в преследование**
    вместо ударов по воздуху (в `attack_enemy` проверка дистанции).

## [0.10.0] — 2026-09-15 (вечерняя сессия)

### Added — Карты разработчиков: рельеф, свет, препятствия
- **Полная расшифровка формата .alm** (проверено на Kids3.alm / Beach.alm):
  - Формальный якорь секций: заголовок секции `[07][20][size][id][32 00 10 14]`, тело сразу после. Тайлы = секция id=1 (`size = W×H×2`), высоты = id=2 (`W×H` int8), препятствия = id=3 (`W×H` u8), строения = id=4 (20 байт × N), юниты = id=6 (48 байт × N)
  - Исправлено: старая эвристика смещения тайлов по связности читала байты со сдвигом в десятки байт → «винегрет». Теперь смещение детерминированное
  - Тайл uint16: биты 12-15 = 0; byte[1] = файл-1 (0-3 → tile1-4); byte[0] = вариант<<4 | ряд
  - Из info: имя/автор карты, угол солнца (solar), время суток, счётчики сущностей
- **Рельеф**: каждый тайл-квад 32×32 поднимается на высоту углов (int8 из секции heights), текстура растягивается под наклон; атлас всех используемых ячеек (файл-вариант-ряд) собирается в одну текстуру загрузчиком
- **Свет от солнца** (методика jewalky/Allods16): угол солнца из info (.alm), нормаль квада через cross-произведение, яркость `|n·sun|·64+96` с контрастом; плоский террейн ~1.0, склоны затемняются
- **Препятствия** (секция obstacles → objects.txt): дерево/камень/статуя с якорем (cx,cy) и анимацией кадров (sprites-001..00N), поднимаются на высоту рельефа, y-sort
- **Строения/здания** (секция id=4 → structures.reg): распознаны 19 строений Kids3 — деревня в центре (церковь/Saving Place, трактир Inn 1, магазин Shop 2, колодец Well 2), мост, хижины, руины, костёр; конвертация спрайтов зданий (house.256 → PNG) выполнена, рендер в процессе
- **Формат спрайтов .256 расшифрован**: палитра 256×4 байта, кадры [w][h][len][RLE], счётчик кадров в конце файла (старший бит = флаг палитры); RLE-токены: `0x00-0x3F` серия пикселей, `0x40-0x7F/0xC0-0xFF` вертикальный пропуск, `0x80-0xBF` горизонтальный пропуск

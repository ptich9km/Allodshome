# Changelog

Все изменения проекта Allods Home (Godot версия) документируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/).

## [0.4.0] — 2026-09-15

### Added
- **Объекты карты из map-objects**: 77 оригинальных объектов (деревья, кусты, камни, статуи, заборы…)
- **База объектов** `object_db.json` (сгенерирована из оригинала `objects.txt`): кадры, расписание анимации, размеры/якорь, dead/fire-связи
- **Покадровая анимация объектов** в реальном времени (8 объектов с анимацией; синхронно по `AnimationTime/AnimationFrame`)
- **Разрушение объектов магией с уроном по области**: огненный шар (радиус 40) и молния (радиус 60) наносят урон объектам; при HP ≤ 0 объект переключается на `dead`-текстуру (пень/руины)
- **Неразрушаемые объекты**: у кого нет `dead/`-папки — урон игнорируется
- **Двухслойный рендер карты**: слой земли + слой объектов; объект «стоит» на земле, а не на сером фоне
- **Земля под объектом** (`under_tiles`): сохраняется в JSON карты, ластик по объекту возвращает её
- В панели «Настройки» объекты помечаются бейджами **A** (анимирован) / **R** (разрушаемый)
- Скрипты: `object_db.gd`, `map_object.gd`

### Changed
- Спецификация объекта: `{"kind":"object","obj":"имя"}` (старые записи с `path` поддерживаются)
- Палитра наборов текстур читается из **`res://assets/maps/map_editor_palette.json`** (была в user://) — наборы синхронизируются через git и используются обоими местами (редактор + игра)
- Кнопка «Новая» снова подтягивает наборы из палитры (не сбрасывает в дефолт)

### Fixed
- **Зависание «Залить область»**: заливка пустой области уходила в бесконечность за границы карты (в `tile_id_at` за границей возвращается -1 = «пусто»); добавлена проверка границ в цикле
- Категории «Строение», «НПЦ», «Спавн» не были видны в настройках текстур (циклы были на 5 категорий, а не 8)
- Серый фон под объектами на карте (объект заменял клетку земли — теперь рендер двухслойный)

## [0.3.0] — 2026-09-14

### Added
- **Декодер оригинальных карт .alm** (`alm_loader.gd`): магия "M7R", ширина/высота, 2 байта/тайл × 2 слоя; старт тайл-секции ищется по пространственной связности
- **Прямой рендер .alm**: `byte[1]` = тип рельефа (0-3 tile1-4, 16-40 вода), `byte[0]` = variant+ряд из пользовательской палитры; вода/скала непроходимы
- **Подключение карты к игре**: `main` грузит `my_map.json` через `CustomMap`, спавн героя берётся из карты (тип «Спавн»), миникарта поддерживает CustomMap
- **8 типов terrain**: Трава, Земля, Песок, Вода, Скала, **Строение, НПЦ, Спавн**
- **Редактор карт** (`map_editor.tscn`): кисть по сетке (1-3 тайла), **заливка области**, **ластик**, **undo (Ctrl+Z)**, управление размером карты, JSON save/load, камера (WASD + зум)
- **Настройки текстур**: для каждой категории собирается набор текстур (tile1-4 × варианты × ряды) с сохранением в палитру
- Игра использует набранные в редакторе текстуры terrain (регионы по `byte[1]`)

### Changed
- Палитра текстур из пользовательских наборов применяется и в .alm-рендере

## [0.2.0] — 2026-09-09

### Added
- Миникарта в правом верхнем углу (зелёная трава, серые стены, синий игрок, красные враги)
- Панель действий: Следовать/Атаковать/Охранять с подсветкой активного режима
- Портрет персонажа в правой панели
- Панель характеристик: сила, ловкость, интеллект, выносливость, дух, урон, броня, защита, опыт, скорость
- 4 новых врага: летучая мышь (20 HP), орк тир2 (70 HP), людоед (100 HP), зомби (80 HP)
- NPC-тролль (80 HP)
- Панель заклинаний 2×12 (24 иконки) из скриншота Allods 2
- Toggle панелей: I — инвентарь, B — заклинания
- Лут-мешки после убийства врагов (3 размера: малый/средний/большой)
- 4 типа лута: золото, зелье HP, зелье маны, руда
- Рестарт сцены по Ctrl+R при смерти

### Changed
- HP/Mana бары над головами персонажей (не дублируются внизу)
- Инвентарь: пустые слоты 10×4 (без стартовых предметов)
- Спрайты врагов: чёрный фон заменён на прозрачность
- Окно увеличено до 1280×800

### Fixed
- Minimap: tilemap находился через группу "tilemap"
- ActionPanel сдвинута ниже миникарты (offset_top=205)
- Health bars подняты выше (position -65)
- Удалены все debug print сообщения
- Ошибка freed object при смерти игрока
- Целочисленное деление в расчёте цветов

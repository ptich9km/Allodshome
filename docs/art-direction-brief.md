# Art direction brief — персонажи Allods Home

> Рабочий документ по шаблону скила `create-game-assets`. Статус: **черновик — ждём одобрения визуального эталона (маг-мужчина)**.
> Провенанс генераций: `bl image` (Aliyun Bailian), все кандидаты проходят ручное одобрение пользователя.

## Game frame

- Player fantasy: тактический RPG-герой в фэнтези-песочнице («духовный наследник Аллодов II», не копия)
- Core verbs: исследовать, сражаться (активная пауза), нанимать отряд, крафт, торговля
- Engine and renderer: Godot 4.7, GL Compatibility, 2D
- Target platforms: Windows (дальше — Steam/itch)
- Camera/view/facing: изометрия 3/4 сверху; юнит рисуется в **5 направлениях** (вниз, вниз-влево, влево, влево-вверх, вверх), правые 3 направления — H-flip зеркала (отдельных кадров нет)
- Native viewport and common display scale: референс 1280×800
- Typical asset size on screen: кадр юнита 128×128 px, тайл 32 px, якорь (cx,cy)=(64,78)

## Visual system

- Shape language: умеренно-угловатые фигуры, читаемые силуэты; маг — высокий, средний телосложение, вертикальный силуэт мантии
- Silhouette priorities: на 64×64 должны читаться класс (маг/воин), пол, поза; плащ/мантия не сливаются с фоном
- Value structure: 3–4 тоновых плана; персонаж светлее/контрастнее тайлов земли
- Palette roles and exact swatches: **зафиксированы по одобренному эталону mage_m_target_001 (2026-09-25):** мантия сине-фиолетовая — `#666699` (основная), `#555588`/`#444477`/`#444466` (средние тени), `#333355` (глубокая тень); волосы/кожа-коричневый — `#775533`, `#664422`, `#553322`; тёмное — `#332211`, `#221111` (контур/провалы). Акцент класса — золото трима (уточнить при производстве). Для воина — своя палитра после его эталона
- Materials and surface cues: ткань (мантия) — мягкие складки; кожа — матовая; металл — узкие яркие блики; дерево посоха — тёплое
- Edge/line treatment: тёмный контур 1 px (не чисто-чёрный — тонированный в локальный цвет), без «грязных» одиночных пикселей
- Lighting direction and contrast: свет слева-сверху, мягкий ambient; допустим слабый rim-light справа-снизу; запечённых теней от сцены нет (тень рисуется кодом отдельно)
- Detail density and focal hierarchy: детализация выше 1999 г. (заказ пользователя «уже 2026»): богатая палитра (~48–64 цвета на персонажа), плавные шейдинг-переходы кластерами 2×2+, фокус деталей — голова/плечи/оружие; низ мантии проще
- Motion character: сдержанно-весомая (как оригинал), без squash&stretch
- Explicit exclusions: фотореализм, 3D-рендер-look, аниме-глаза, неоновая палитра, текст/подписи на арте

## Technical contract

- Asset dimensions/aspect: кадр 128×128; холст генерации-исходника 512×512 (даунскейл)
- Alpha/background: прозрачный фон (генерация на пурпурном #FF00FF + программный кеинг Python/PIL)
- Grid/tile/frame size: раскладка набора героя — **129 кадров** (idle 9; move 5×10; attack 5×7; dying 5×4; decay 5×3; направление-мажор: frame = block_start + dir×phases + phase)
- Anchor/pivot/baseline: (64,78), низ спрайта = точка контакта с землёй
- Filtering/mipmaps/compression: nearest (пиксель-арт), mipmaps off, lossless PNG
- Color space: sRGB
- Texture/poly/material budgets: один набор ≈ 129×128×128×4 Б ≈ 8.4 МБ в памяти; цель — не превышать текущее число наборов (30 heroes)
- Naming and folders: `assets/units/heroes{,_l}/<set>/sprites-NNN.png` — формат и имена НЕ меняются (код `UnitAnim`/`anim_set_name()` не трогаем); новые тела/слои — `assets/units/_layers/` (wip — вне git до одобрения)

## Персонажи (матрица)

- Пол: male / female — **должен быть виден в игре** (сейчас `Game.hero_gender` не влияет на спрайт — исправим через разные базовые тела)
- Классы героя: воин (М/Ж), маг (М/Ж)
- Маг-мужчина (описание пользователя, 25.09): **высокий человек среднего телосложения, волосы средней длины коричневые, одежда мага видна на модели**; качество выше уровня 1999 года
- Маг-женщина, воин М/Ж: описания ждём от пользователя
- Слои (bake-подход): тело(пол×класс) × одежда/броня(лёгкая/тяжёлая) × оружие(меч/топор/булава/пика/лук/арбалет/посох/магия) × щит → запекаются скриптом в существующую 129-кадровую раскладку

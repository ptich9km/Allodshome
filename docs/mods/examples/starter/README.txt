ШАБЛОН МОДА
===========

Что делать:
 1. Скопируйте эту папку (starter) в папку модов:
    в игре: главное меню -> «Моды и дополнения» -> «Открыть папку».
 2. Переименуйте папку, например в  my_mod.
 3. В mod.json поменяйте "id" на  my_mod — id ОБЯЗАН совпадать с именем папки,
    иначе мод не загрузится (в списке модов будет ошибка).
 4. Правьте записи в data/. Здесь один зверь, который наследует волка:
    меняете name_ru, tier, palette и получаете своего монстра.
 5. В игре: «Моды и дополнения» -> «Обновить». Мод должен появиться в списке
    без красных ошибок. Включение и порядок применяются после перезапуска.

Формат записи:
 {"kind": "...", "key": "...", "op": "add|patch|remove|append", "extends": "...", ...поля}

 kind: item | unit | spell | structure | rule
 Полная спецификация: docs/mods.md
 Пошаговое руководство: docs/mods-first.md

Проверка без запуска игры:
 godot --headless --path . --script res://tests/mod_validate.gd -- ПУТЬ_К_ПАПКЕ

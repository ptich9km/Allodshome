# Roadmap: механики Rage of Mages II / Allods 2 (по приоритетам)

Цель проекта — **полноценный редактор карт + игра-песочница** («выбери героя и играй
в своё удовольствие»). Игровые сценарии и кампания из оригинала НЕ переносятся.
Этот файл сопоставляет механики RoM2 (из `docs/rom2-ref` — оригинальные данные
игры: help.txt, town.txt, building.txt, spells.txt, quest.txt, itemserv.txt) с тем,
что уже есть в Allodshome, и предлагает, что сделать дальше.

## Уже реализовано (фундамент готов)
- Рельеф + солнечное освещение, анимация воды, здания (структуры), препятствия-деревья
- Выбор героя (4 персонажа, пол/класс), статы Body/Agility/Mind/Spirit по формулам оригинала
- Инвентарь: 491 предмет из data.bin (реальные цены/вес/характеристики), экипировка кликом
- Магия: 31 заклинание, книги стихий, свитки; телепорт заклинанием
- НПЦ: мирные жители, монстры (79 на Kids3), агро/патруль, звуки, ховер-портреты
- Режимы команд (следовать/атаковать/охранять/стоп), тактическая пауза, миникарта
- Редактор: кисть/заливка/undo, структуры, НПЦ, объекты-деревья, «Выбор»-инспектор,
  sidecar-файлы, импорт .alm

## P0 — «как у разработчиков»: экономика и прокачка (без этого песочница не играется)

### 1. Золото и **торговля (Shop)** — данные есть: здания `Shop` (building.txt), в .alm секция 11 (options: inns+shops)
- У героя появляется `gold` (сейчас — только в data из игроков, `_read_players`).
- Отдельная панель магазина (полки: оружие/броня/амулеты/кольца/зелья/свитки):
  покупка за золото, продажа лута. Цены уже в `item_db.json` (price).
- Ассортимент — «генератор качества» в стиле itemserv.txt
  (`Bad/Common/Elven/Royal… × материал`), цены масштабируются от уровня карты.
- Куда: узел `Shop` в структурах → `usable` (в structure_db уже есть поле `usable`).
- Враги-гуманоиды должны ронять **то, что на них надето** (оригинальная механика).

### 2. Лут с врагов (сейчас `_drop_loot` в enemy.gd отключён!)
- Включить: мешок/прямое падение золота + зелья + предметы экипировки монстра.
- Кнопка `P` — «подобрать все мешки» (из help.txt).

### 3. Таверна/Инн (**Inn**): наём наёмников и слухи
- Клик по зданию Inn → окно с портретами наёмников (зеленоватый фон), кнопки
  **Hire / Talk** (как в town.txt #tips2).
- Наёмники идут за героем, бьют врагов, не качаются (как в оригинале),
  автоматически «прокачиваются» между заданиями.
- Talk — короткие диалоги/слухи (см. P2.14), оттуда же выдаются контракты (P2.13).

### 4. Школа тренировок (**Training School** — building.txt)
- За золото мгновенно поднять навык оружия/магии (цена растёт с уровнем навыка:
  «prices become really ridiculous» — так и надо).
- Навыки уже есть (`blade_skill…astral_skill`), привязки к урону/защите сделаны.

### 5. Создание персонажа «как в оригинале» (tips5–7)
- Распределитель очков: уменьшил атрибут → очки на другие (сейчас фикс. 10/10/10/10).
- «Склонность»: +20 к одному оружейному навыку или одной стихии при создании.

## P1 — игровые системы

### 6. Полный спектр заклинаний (spells.txt — базовые блоки есть, не хватает механик)
- **Области-эффекты**: Wall of Fire / Poison Cloud / Blizzard / Wall of Earth
  (непрерывный урон/блок на клетках, а не мгновенный удар).
- **Бафы/дебафы**: Bless (шанс максимума урона), Haste (скорость), Shield
  (поглощение), Protection-резисты, Stone Curse (паралич), Invisibility
  (невидимость — враги не агр.
- **Некромантия** (фишка «Повелителя душ»): Animated Dead — подъём зомби/скелета/
  духа из трупа; Summon — призыв монстра (суммон в player.gd — задел).
- Автокаст (Ctrl+U) и шорткаты F4–F12 (Ctrl+A — выбор заклинания для автокаста).

### 7. Тактика отряда (help.txt)
- **Стойки**: Defend (D), Swarm (S: движение+атака), Retreat (R), Stand Ground (T),
  Stand Still (L) — расширить панель команд (сейчас follow/attack/guard/stop).
- Формации (Ctrl+F), группы выделения 1–9, выбор «всех наёмников» (E).

### 8. Использование предметов
- Зелья HP/маны — использовать из инвентаря (классы Potion есть в item_db).
- Свитки — одноразовые заклинания; книги — обучение (уже есть классы Book/Scroll).

### 9. День/ночь (Ctrl+N в оригинале)
- Цикл: освещение солнца (у нас уже real-time) + затемнение ночью; стартовая
  `time_of_day` уже читается из .alm info — можно подключить.

## P2 — «полноценный редактор» и мир-песочница

### 10. Связка карт (ворота/телепорты) — главное для редактора
- В editor: ставить **Teleport Pad / Gate**: запись `{карта, x, y}` — переход между
  .alm-картами. Организация: папка-«мир» из нескольких карт.
- Здания «Teleport Pad», «Guard Tower», «Road Sign» уже есть в структурах — дать им смысл.

### 11. Интерактив строений (building.txt → структуры уже отрисованы)
- **Magic Well** — восстановление HP/маны при клике; **Altar** — постоянный/временный баф;
- **Campfire** — точка сохранения/отдых; **Sphinx** — загадка (вопрос-ответ, награда);
- **Switch / Magic Symbol** — переключатели, открывающие ворота/двери (головоломки);
- **Grave** — некромантский контент / воскрешение трупов;
- **Road Sign** — подсказка при ховере (у нас уже есть ховер по зданиям — расширить контентом).
- В structure_db.json уже есть поля `usable`, `indestructible` — использовать.

### 12. Генератор контрактов (на базе quest.txt, БЕЗ кампании)
- В таверне выдаются случайные задания по типам из quest.txt:
  1) убить конкретного врага, 2) N особей вида, 3) группу, 5) доставить предмет,
  6) срочное сообщение (по времени), 7) найти предмет, 8–10) привести N зомби/скелетов/
  духов (некромантия!) — награда золотом в таверне. Журнал по клавише W.

### 13. Диалоги НПЦ (dialogs.txt — условия IAMMALE/IAMFIGHTER по полу/классу)
- Простое окно диалога при клике на жителя: реплики расходятся по полу и классу героя.

### 14. Малые опции интерфейса оригинала (help.txt)
- TAB — переключение «портрет ⇄ характеристики» в инфо-панели; Ctrl+H — показ HP;
  Ctrl+L — летящие цифры урона; «+/-» — скорость игры; F2/F3 — сохранить/загрузить.

## Что НЕ делаем (осознанно)
- Кампанию/сюжетные миссии (`mission*.txt`), пошаговые сценарии, катсцены.
- Мультиплеер/дипломатию/чат (#kick/#locate и пр.).
- Репутацию/отношения городов — в оригинале системы нет (подтверждено обзорами).

## Порядок работ (предлагаемый)
1. **P0 (1–5)** — экономика: золото → шоп → лут → школа → создание героя. После этого
   цикл «убил → продал → прокачался» работает, как у разработчиков.
2. **P1.6–7** — докрутить заклинания (область/бафы/некромантия) и команды отряда.
3. **P2** — связка карт + интерактив строений + контракты — это уже «полноценный
   редактор и мир».
4. **P1.8–9, P2.14** — зелья/день-ночь/мелкие опции — полировка в любой момент.

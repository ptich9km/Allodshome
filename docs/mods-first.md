# Первый мод за полчаса

Пошагово: от пустой папки до мода, который видно в игре. Никакого кода — только
JSON. Полная спецификация формата: `docs/mods.md`.

## 0. Что понадобится

- Любой текстовый редактор (Notepad++ / VS Code / даже Блокнот).
- Запущенная игра один раз (она создаёт папку модов).

## 1. Открыть папку модов

Главное меню → **«Моды и дополнения»** → **«Открыть папку»**.

Откроется `%APPDATA%\Godot\app_userdata\Allods Home\mods`. Сначала она пустая —
это нормально.

## 2. Скопировать шаблон

Скопируй папку `docs/mods/examples/starter` в открытую папку модов и переименуй
её, например, в `my_mod`.

```
mods/my_mod/
  mod.json
  data/units.json
```

## 3. Поменять id

Открой `mod.json`. Поле `id` **обязано совпадать с именем папки**:

```json
{
  "id": "my_mod",
  "name": "Мой первый мод",
  "version": "0.1.0",
  "author": "твой ник"
}
```

Если не совпадёт — мод не загрузится (в панели модов будет ошибка).

## 4. Поменять запись

`data/units.json` — один зверь, который наследует волка:

```json
[
  {
    "into": "unit",
    "key": "monsters/my_beast",
    "extends": "monsters/wolf",
    "name_ru": "Мой зверь",
    "tier": 2,
    "palette": 5
  }
]
```

- `key` — имя набора. Начинай с `monsters/`, иначе игра не сочтёт его врагом.
- `extends` — у кого копируем кадры и служебные поля. `monsters/wolf` — волк,
  12 кадров, готовый арт. Своей графики пока нет — и не нужно.
- `palette: 5` — «враждебная» палитра (без неё зверь будет мирным).
- `tier` — сила (1..5).

Поменяй `name_ru` и `tier` — это уже другой зверь.

## 5. Проверить, не запуская игру

В папке проекта:

```powershell
& 'C:\Games\Godot_v4.7.2-stable_win64_console.exe' --headless --path . `
  --script res://tests/mod_validate.gd -- "%APPDATA%\Godot\app_userdata\Allods Home\mods\my_mod"
```

Валидатор ловит опечатки: битый JSON, `id` ≠ папка, неизвестный `into`,
`add` на занятый ключ, `extends` в никуда, отсутствующие файлы.
Хороший результат — `RESULT: OK mod_validate`.

## 6. Включить в игре

Вернись в игру → «Моды и дополнения» → **«Обновить»**. Мод появится в списке:
имя, версия, автор, буква вместо превью (пока нет `thumb.png`).

Если под строкой красный текст — это ошибки мода, читай их. Ничего не сломалось:
игра работает на базовых данных.

⚠️ Включение и порядок применяются **после перезапуска игры**. Перезапусти.

## 7. Увидеть результат

Зверь попадёт в мир, только если его **вид** есть в списке видов Серых. Добавь
правило — отдельный файл `data/rules.json`:

```json
[
  {"into": "rule", "op": "append", "key": "spawn.gray_species", "value": ["my_beast"]}
]
```

Имя вида — это то, что после `monsters/`. Перезапусти игру и иди в стартовую
зону: там водятся тиры 1–2, то есть `monsters/my_beast`.

> Проверить проще всего в бою: если зверь напал и у него правильное имя — мод
> работает. Если зверь умер «сам» — рядом прошла стычка монстров, это нормально.

**Предметы в лавке — не все.** Лавка торгует зельями, свитками, книгами и
рецептами, но **не** оружием и бронёй: экипировка падает с врагов. Так что
корону из примера `scourge` в лавке искать бесполезно — а книга школы `Shadow`
(качество `Book`, цена > 0) там появляется и открывает всю школу.

## 8. Что дальше

| Хочу | Куда смотреть |
|---|---|
| Новый предмет | `into: "item"`, поля как в `assets/items/item_db.json`; оружие и броня падают с врагов, зелья/свитки/книги/рецепты продаются в лавке |
| Новое заклинание | `into: "spell"`, см. `assets/spells/spells_db.json` |
| Новая школа магии | `rule` + `append` в `spells.spheres`, затем заклинание с этим `sphere` |
| Новый тип брони | `rule` + `append` в `items.head_types` (или другой слот), затем предмет с этим `type` |
| Своя картинка | положи PNG в `assets/` мода и сошлись на `mod://my_mod/assets/…` |
| Поменять баланс | `op: "patch"` по ключу существующего объекта |

Готовые примеры: `docs/mods/examples/` (`warden` — зверь и предмет,
`scourge` — школа магии, тип брони, заклинание и зверь в спавне).

## Частые ошибки

| Симптом | Причина |
|---|---|
| Мода нет в списке | Папка лежит на уровень глубже: нужен `mods/my_mod/mod.json`, а не `mods/my_mod/my_mod/mod.json` |
| «id не совпадает с папкой» | Переименовал папку, но не `id` (или наоборот) |
| «ключ уже есть в игре» | `add` по существующему имени — для правки нужен `op: "patch"` |
| «extends не найден» | Опечатка в имени набора или он из другого мода, который выключен |
| «файл не найден: mod://…» | Путь указан на другой id или файла нет |
| Зверь не встречается | Нет правила `spawn.gray_species` (шаг 7) |
| Зверь мирный | Нет `palette: 5` |

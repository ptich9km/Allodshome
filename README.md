# 🎮 Allods Home - Godot 4

## ✅ Что сделано

Ваша 2D изометрическая RPG перенесена из Unity в Godot 4!

### Реализовано:
- ✅ **Изометрическая карта** - ромбовидный остров с тайлами травы и стен
- ✅ **Персонаж** - ваш спрайт воина с клик-ту-мув
- ✅ **Враги** - 2 орка + 1 слизень с AI (патруль → погоня → атака → побег)
- ✅ **Боевая система** - melee + 3 заклинания (fireball, heal, lightning)
- ✅ **UI** - HP/Mana бары + панель заклинаний
- ✅ **Тактическая пауза** - пробел

## 🚀 Быстрый старт

### 1. Установите Godot 4
Скачайте с официального сайта: https://godotengine.org/download
Выберите **Godot 4.x** (стандартная версия)

### 2. Откройте проект
- Запустите Godot
- Нажмите **"Import"**
- Выберите папку: `D:\Work\UnityProjects\Allodshome_Godot`
- Нажмите **"Import & Edit"**

### 3. Запустите игру
- Откройте сцену: `scenes/main.tscn`
- Нажмите **F5** или кнопку ▶️ (Play)

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **ЛКМ по земле** | Движение к точке |
| **ЛКМ по врагу** | Атака врага |
| **1** | Fireball (огненный шар) |
| **2** | Heal (лечение) |
| **3** | Lightning (молния) |
| **Пробел** | Тактическая пауза |

## 🆚 Сравнение с Unity

| Аспект | Unity | Godot |
|--------|-------|-------|
| **Размер проекта** | 600+ строк boilerplate | ~300 строк кода |
| **Импорт ассетов** | Настройка TextureImporter | Drag & drop |
| **TileMap** | Ручная настройка + код | Встроенный изометрический |
| **Время итерации** | Компиляция → Play | Мгновенный запуск |
| **Редактор сцен** | Визуальный + код | Визуальный + код |
| **Язык** | C# | GDScript (как Python) |

##  Почему Godot лучше для этого проекта

1. **Быстрее разработка** - не нужно компилировать, изменения видны сразу
2. **Проще ассеты** - перетащите PNG в папку - и они готовы
3. **Встроенный TileMap** - изометрия работает из коробки
4. **Меньше кода** - GDScript короче C# в 2-3 раза
5. **Лёгкий движок** - 40MB vs 2GB+ у Unity
6. **Бесплатный навсегда** - нет лицензионных ограничений

## 🔧 Технические детали

## 🐛 Если что-то не работает

1. Убедитесь что у вас **Godot 4.4+** (не 3.x!)
2. Проверьте что все файлы на месте (особенно `.tscn` и `.gd`)
3. Откройте `Output` панель в Godot для просмотра ошибок
4. Попробуйте перезапустить Godot

# 🎮 Allods Home - Godot 4

2D изометрическая RPG-реконструкция **«Allods 2 / Rage of Mages II»** (Проклятые земли) на Godot 4.
Проект сочетает порт игрового прототипа с Unity и **реверс-инжиниринг оригинальных ресурсов**
(карты `.alm`, спрайты `.256`, тайлсеты, объекты карты) плюс собственный **редактор карт**.

## ✅ Что сделано

### Игра
- ✅ **Карта из оригинальной игры**: декодирован бинарный формат `.alm` (`Beach.alm` 256×256 и другие) — 2 слоя по 2 байта/тайл, типы рельефа (трава/земля/песок/вода/скала), высоты и объём
- ✅ **Своя карта в игре**: `assets/maps/my_map.json` (64×64) рисуется в редакторе и грузится игрой через `CustomMap`
- ✅ **Объекты карты (map-objects)**: деревья, кусты, камни, статуи из оригинальных ассетов:
  - **покадровая анимация** в реальном времени (по расписанию из `objects.txt`)
  - **разрушение уроном по области** (огненный шар, молния): HP, при смерти объект меняется на `dead`-текстуру
  - объекты без `dead/`-папки **неразрушаемы**
- ✅ **Персонаж** - спрайт воина с клик-ту-мув, проходимость учитывает карту
- ✅ **Враги** - AI (idle → погоня → атака → побег), HP-бары
- ✅ **Боевая система** - melee + 3 заклинания (fireball, heal, lightning)
- ✅ **UI** - HP/Mana бары, панель заклинаний 2×12, миникарта по реальным данным карты, портрет и характеристики
- ✅ **Тактическая пауза** - пробел

### Редактор карт (`scenes/map_editor.tscn`)
- ✅ **8 категорий terrain**: Трава, Земля, Песок, Вода, Скала, **Строение, НПЦ, Спавн**
- ✅ **Наборы текстур на категорию**: в «Настройках…» собираете палитру из 68 тайлов terrain (tile1-4 × варианты × ряды) и **77 объектов map-objects** (бейджи A — анимирован, R — разрушаемый)
- ✅ Палитра сохраняется в `assets/maps/map_editor_palette.json` (в git — синхронизируется между устройствами)
- ✅ Кисть по сетке с размером (1-3), **заливка области**, **ластик** (снимает объект, возвращая землю), **undo (Ctrl+Z)**
- ✅ Земля под объектом: объекты рисуются **поверх земли** в отдельном слое (двухслойный рендер), а не заменяют её
- ✅ Изменение размера карты, JSON save/load, камера WASD + колесо зум
- ✅ Точка спавна героя (тип «Спавн») из карты

## 🚀 Быстрый старт

1. **Godot 4.x** — скачайте с https://godotengine.org/download (стандартная версия)
2. Откройте проект: **Import** → папка `C:\Work\Allodshome` → **Import & Edit**
3. Запустите игру: откройте `scenes/main.tscn` → **F5**
4. Или редактор карт: `scenes/map_editor.tscn` → **F5** (кнопка «Назад в игру» возвращает в main)

## 🎮 Управление (игра)

| Клавиша | Действие |
|---------|----------|
| **ЛКМ по земле** | Движение к точке |
| **ЛКМ по врагу** | Атака врага |
| **1** | Fireball (огненный шар, урон по области) |
| **2** | Heal (лечение) |
| **3** | Lightning (молния, урон по области) |
| **Пробел** | Тактическая пауза |
| **Ctrl+R** | Рестарт сцены |
| **I / B** | Тoggle инвентаря / заклинаний |

## 🛠 Редактор карт — управление

| Действие | Как |
|----------|------|
| Выбрать категорию | Кнопки палитры слева (Трава…Спавн) |
| Выбрать текстуру | Полоса «Текстура» под палитрой (из набора категории) |
| Рисовать | ЛКМ по карте (размер кисти 1-3) |
| Залить область | Кнопка «Залить область» → клик в зону |
| Стереть | «Ластик» (по объекту — вернёт землю) |
| Отменить | Ctrl+Z |
| Камера | WASD / стрелки, колесо — зум |
| Настройки текстур | Кнопка «Настройки…» — собрать наборы на категорию |
| Сохранить/Загрузить | Кнопки «Сохранить» / «Загрузить» (my_map.json) |

## 🔧 Технические детали

- **Версия Godot**: 4.7+ (рендерер — GL Compatibility)
- **Разрешение**: 1280×800 (canvas_items stretch)
- **Сетка карты**: 32×32 клетки, TileMapLayer
- **Формат .alm**: магия `"M7R"`, ширина/высота на смещениях 0x28/0x2c; 2 байта на тайл × 2 слоя; `byte[1]` — тип рельефа (0-3 → tile1-4, 16-40 → вода, иначе барьер), `byte[0]` — autotile-вариант (ниббл → файл, старшие биты → ряд)
- **JSON-карта** (`my_map.json`): `{width, height, tiles, tex_ids, under_tiles, texture_sets}`
- **Объекты**: `object_db.json` сгенерирован из оригинального `objects.txt` (кадры, тайминги анимации, размеры/якорь, `dead`/`fire`-связи); спецификация объекта — `{"kind":"object","obj":"имя"}`

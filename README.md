# 🎮 Allods Home — Godot 4.7

2D изометрическая **песочница + тактический RPG** — духовный наследник «Аллодов II / Проклятые земли» на Godot 4.7 (GDScript 2.0).

Не копия оригинала, а собственная игра с процедурной генерацией карт, фракциями, городами, SIM-эмуляцией мира и единой математикой боя.

## ✅ Что реализовано

### Мир и генерация карт
- **Процедурный генератор** (`gen_smart_map.gd`): Voronoi-биомы, города (овалы ~15×15 из дорог), MST-дороги через A*, горы/вода поверх без перетирания дорог
- **7 типов terrain** + объекты/спавн: трава, горы, вода, дорога, почва, песок, грязь — каждый со своими BMP-тайлами и переходами
- **Переходы между terrain** (336 правил): shape-based подбор форм, «универсальный край» row 4, `transition_db.json` + визуальный редактор (`transition_editor.gd`)
- **Псевдо-высоты** (bilinear sampling): подъём мягко замедляет, горы усиливают
- **SIM-слой** (`scripts/world/`): `WorldState`, `WorldBus` (autoload), `WorldSim` — симуляция дней, фракции, угроза, журнал; headless-раннер на 100 дней

### Боевая система
- **Единая точка урона** — `Game.deal_damage(...)`: вся математика (попадание, броня, защита стихии, щиты) в одном месте (`scripts/game.gd`)
- **Герой**: ближний бой + мгновенная магия (сфера из `SpellDB`), опыт сферам
- **Враги**: AI (idle → погоня → атака → побег), приоритет игроку или ближайшему стражу
- **Наёмники**: атака через `Game.*`, лимит отряда 4
- **Снаряды**: одиночный + AoE-урон через `Game.deal_damage_area`
- **Тактическая пауза** (пробел) — полная остановка + приказы

### Фракции и NPC
- **5 фракций**: Альянс Света, Орды Огня, Пожинатели, Круг Друидов, Серые (всегда враги)
- **Репутация** → качество наёмников и тир магазинов
- **Города**: здания (магазин, таверна, кузница, тренировочные, жильё, декор), стражи (патруль + посты), капитан, жители
- **Серые**: кластеры 2–4 особей у дорог и в лесу

### Здания и профессии
- **Магазин** (`shop_panel.gd`): 5 категорий, ScrollContainer, покупка/продажа, книги мага
- **Таверна** (`inn_panel.gd`): 10 кандидатов, найм в отряд, разговор с рекрутером
- **Кузница** (`blacksmith_panel.gd`): переплавка экипируемых предметов → слитки (15 маппингов материалов)
- **Druid Shop** (`alchemy_panel.gd`): data-driven рецепты (`recipes.json`), атомарный расход ингредиентов
- **Травничество**: 8 трав (`item_db.json`), `HerbNode` (сбор + регенерация 180с), стратифицированная генерация (20–30 по зоне)

### Персонаж и прогрессия
- **Клик-ту-мув** с A*-навигацией, обход озёр по берегу
- **Инвентарь**: подбор лута, экипировка, золото
- **Зоны Z1–Z4**: прогрессия от обучения до территорий фракций
- **Физика interpolation**: плавное движение на 60 Гц, `reset_physics_interpolation()` после телепортов

### UI
- **Контейнерный подход**: `GridContainer`/`ScrollContainer`/`VBoxContainer` вместо ручного размещения
- **Единая тема** (`Theme`), масштабирование от референсного 1280×800
- **Полный ввод**: мышь + клавиатура + геймпад, начальный фокус, навигация, `Esc`
- **Миникарта** по реальным данным карты, HP/Mana бары, портрет и характеристики

### Редактор карт (`scenes/map_editor.tscn`)
- 8 категорий terrain + объекты + спавн
- Палитра текстур, кисть 1–3, заливка, ластик, undo (Ctrl+Z)
- Визуальный редактор переходов (`transition_editor.gd`): сетка 3×3, импорт из `.alm`
- Экспорт в `.alm` (формат оригинала: магия `M7R`, секции info/tiles/heights/obstacles)
- F9 — возврат в игру с последней отредактированной картой

## 🚀 Быстрый старт

1. **Godot 4.7+** — https://godotengine.org/download
2. Import → папка проекта → Import & Edit (первый запуск: `--headless --import` для импорта сотен ассетов)
3. Игра: `scenes/character_select.tscn` → F5 (выбор героя → `main.tscn`)
4. Редактор карт: `scenes/map_editor.tscn` → F5

### Headless-проверки
```bash
# Парсинг скриптов (нет SCRIPT ERROR = OK)
godot --headless --path . --quit 2>&1 | grep 'SCRIPT ERROR'

# SIM-симулятор (100 дней)
godot --headless --path . --script res://scripts/world/sim_runner.gd

# Рендер карты → PNG
godot --headless --path . --script res://tests/render_alm_png.gd
```

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **ЛКМ по земле** | Движение (A* + обход препятствий) |
| **ЛКМ по врагу** | Атака |
| **ЛКМ по зданию** | Открыть панель (магазин/таверна/кузница/алхимия) |
| **ЛКМ по траве** | Сбор (в радиусе подхода) |
| **1–4** | Заклинания / сферы мага |
| **Пробел** | Тактическая пауза |
| **I** | Инвентарь |
| **Esc** | Закрыть панель |

## 🔧 Технические детали

- **Движок**: Godot 4.7, GDScript 2.0, GL Compatibility
- **Разрешение**: 1280×800 (canvas_items stretch), равномерный масштаб UI
- **Сетка**: 32×32, TileMapLayer, uint16-кодировка тайла
- **Autoload**: `WorldBus` (единственный)
- **Формат .alm**: магия `0x0052374D`, секции info(660Б)/tiles(uint16)/heights(int8)/obstacles(uint8)
- **Physics interpolation**: включён, сброс после телепортов

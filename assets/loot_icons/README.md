# Loot Icons — Allodshome

Ассеты для системы лута. Все файлы — PNG с прозрачным фоном.

---

## Мечи (Swords) — 19 файлов

Выпадают с убитых врагов как лут.

**Формат:** 32×32 PNG, прозрачный фон, 3D-рендер (перекраска реального фото).

**Именование:** `{material}_weapon.png`

---

## Нагрудники (Chest Armor) — 19 файлов

Выпадают с убитых врагов как лут.

**Формат:** 32×32 PNG, прозрачный фон, 3D-рендер (перекраска реального фото).

**Именование:** `{material}_armor.png`

---

## Слитки металлов (Metal Ingots) — 19 файлов

Выпадают после переплавки брони/оружия в кузнице.

**Формат:** 80×80 PNG, прозрачный фон, 3D-рендер (перекраска реального фото).

**Именование:** `{material}_ingot.png`

---

## Бутылки (Potion Bottles) — 6 типов × 4 кадра

Анимированные бутылки маны и жизни для лута.

**Типы:**
- `health` — бутылка жизни (красная жидкость)
- `mana` — бутылка маны (синяя жидкость)

**Размеры:**
- `small` — маленькая
- `medium` — средняя
- `large` — большая

**Файлы:**
- `{type}_{size}_frame{00-03}.png` — отдельные кадры (32×32)
- `{type}_{size}_spritesheet.png` — 4 кадра в строке (128×32)

**Анимация:** покачивание (bobbing) + блик на жидкости

## Использование в Godot

```gdscript
# Лут меча с врага
var sword = load("res://assets/loot_icons/cobalt_weapon.png")  # 32x32

# Лут нагрудника с врага
var armor = load("res://assets/loot_icons/cobalt_armor.png")  # 32x32

# Слиток после переплавки
var ingot = load("res://assets/loot_icons/cobalt_ingot.png")  # 80x80

# Анимированная бутылка
var sprite = AnimatedSprite2D.new()
var frames = SpriteFrames.new()
var sheet = load("res://assets/loot_icons/health_small_spritesheet.png")
frames.add_sprite_frame("default", sheet, 0.15)
sprite.sprite_frames = frames
sprite.play()
```

**Поток:** враг умирает → выпадает `{material}_weapon.png` или `{material}_armor.png` → игрок приносит в кузницу → получает `{material}_ingot.png`.

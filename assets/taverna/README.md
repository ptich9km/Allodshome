# Taverna UI — Allodshome

Интерфейс казармы (наём солдат у рекрутера). Фоновое изображение — `cf5d15fbb82c11f18effeea93894b2af_1.jpeg` (1024×1024).

---

## Зоны интерфейса

Все координаты в пикселях относительно изображения 1024×1024.

### Панели казармы

| Зона | Координаты | Ячейки | Размер ячейки | Назначение |
|------|-----------|--------|---------------|------------|
| **RECRUIT_PANEL** | (26, 136) — (219, 889) | 7×2 = 14 | 96×108 | Панель солдат на наём у рекрутера (левая панель). Игрок выбирает солдата → солдат нанимается в отряд. |

---

## Логика работы казармы

1. **Открытие казармы:** игрок кликает на строение таверна → открывается UI с фоновым изображением.
2. **RECRUIT_PANEL:** отображает доступных для найма солдат (рыцари, маги, лучники и др.). Игрок выбирает солдата → солдат добавляется в отряд игрока за золото.
3. **Рекрутер:** NPC за столом (правая часть изображения). Игрок может поговорить с рекрутером и взять задание.

## Использование в Godot

```gdscript
# Загрузка фона казармы
var taverna_bg = load("res://assets/taverna/cf5d15fbb82c11f18effeea93894b2af_1.jpeg")

# Координаты зон
const ZONES = {
    "recruit_panel": {"x1": 26, "y1": 136, "x2": 219, "y2": 889, "rows": 7, "cols": 2},
}

# Расчёт позиции ячейки
func get_cell_position(zone: Dictionary, row: int, col: int) -> Vector2:
    var cell_w = (zone.x2 - zone.x1) / zone.cols
    var cell_h = (zone.y2 - zone.y1) / zone.rows
    return Vector2(zone.x1 + col * cell_w, zone.y1 + row * cell_h)
```

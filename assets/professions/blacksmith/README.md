# Import Assets — Allodshome

## Metal Ingots (слитки металлов)

19 файлов слитков для системы переплавки: игрок собирает броню/оружие с врагов и переплавляет в слитки.

**Формат:** 80×80 PNG, прозрачный фон, изометрический 3D-рендер.

**Структура именования:** `{material}_ingot.png`

### Использование в игре

**Переплавка:** игрок собирает броню/оружие с убитых врагов → кузница переплавляет в слиток соответствующего материала.

**Загрузка в Godot:**
```gdscript
var ingot_path = f"res://import/{material}_ingot.png"
var texture = load(ingot_path)
```

**Пример:** при убийстве врага в броне из `cobalt` → выпадает `cobalt_armor.png` → кузница переплавляет → `cobalt_ingot.png`.

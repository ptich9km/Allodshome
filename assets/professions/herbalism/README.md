# Herbalism Profession — Allodshome

Травы для профессии травничества. Игрок собирает растения в мире, использует для создания зелий.

---

## Травы (Herbs) — 8 видов

Выпадают при сборе растений в игровом мире.

**Формат:** 32×32 PNG, прозрачный фон, 2D-арт (разрезка из листа).

**Именование:** `{herb_name}.png`

### Список трав

| Файл | Название | Описание |
|------|----------|----------|
| `green_leaf.png` | Зелёный лист | Молодое растение, базовый ингредиент |
| `white_flower.png` | Белый цветок | Ромашка, используется в лечебных зельях |
| `red_berry.png` | Красная ягода | Ягоды, используются в зельях здоровья |
| `tall_grass.png` | Высокая трава | Травянистое растение, базовый ингредиент |
| `lavender.png` | Лаванда | Фиолетовые цветы, используются в зельях маны |
| `mint.png` | Мята | Мятные листья, охлаждающий эффект |
| `dandelion.png` | Одуванчик | Жёлтый цветок, универсальный ингредиент |
| `broad_leaf.png` | Широкий лист | Крупные листья, защитные зелья |

---

## Использование в игре

```gdscript
# Загрузка травы
var herb = load("res://assets/professions/herbalism/lavender.png")  # 32x32

# Пример: игрок собирает лаванду
func on_herb_collected(herb_name: String):
    var herb_icon = load(f"res://assets/professions/herbalism/{herb_name}.png")
    inventory.add_item(herb_name, herb_icon)
```

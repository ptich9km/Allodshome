## Логика работы магазина

1. **Открытие магазина:** игрок кликает на строение магазин → открывается UI с `shop_human.jpeg` как фон.
2. **NPC_SHELF:** отображает товары NPC. Игрок может купить предмет → предмет переходит в инвентарь игрока.
3. **PLAYER_SHELF:** отображает вещи игрока. Игрок может продать предмет → предмет переходит к NPC, игрок получает золото.
4. **PLAYER_TAB:** 4 слота для иконок персонажей (выбор активного персонажа для торговли).
5. **BOOKS_SHELF:** область ссылка по продаже книги/свитки, при нажатии на неё в меню NPC_SHELF появляется список товаров на продажу с описанием и ценой.
6. **POTIONS:** область ссылка по продаже зелья мана/жизнь и т.д, при нажатии на неё в меню NPC_SHELF появляется список товаров на продажу с описанием и ценой.
7. **ARMOR:** область ссылка по продаже рыцарские доспехи, при нажатии на неё в меню NPC_SHELF появляется список товаров на продажу с описанием и ценой.
8. **ROBE:** область ссылка по продаже доспехи магические, при нажатии на неё в меню NPC_SHELF появляется список товаров на продажу с описанием и ценой.
9. **WEAPON:** область ссылка по продаже оружие обычное и магическое, при нажатии на неё в меню NPC_SHELF появляется список товаров на продажу с описанием и ценой.
10. **MERCHANT:** поговорить с продавцом и взять задание.

## Использование в Godot

```gdscript
# Загрузка фона магазина
var shop_bg = load("res://assets/shop/shop_human.jpeg")

# Координаты зон (для размещения UI-элементов)

    "npc_shelf": {"x1": 26, "y1": 231, "x2": 217, "y2": 835, "rows": 7, "cols": 2},

    "player_tab": {"x1": 216, "y1": 899, "x2": 616, "y2": 990, "rows": 1, "cols": 4},
    "books_shelf": {"x1": 819, "y1": 473, "x2": 997, "y2": 843, "rows": 4, "cols": 1},
    "potions": {"x1": 642, "y1": 842, "x2": 1001, "y2": 998, "rows": 1, "cols": 4},
    "armor": {"x1": 60, "y1": 40, "x2": 180, "y2": 200},
    "robe": {"x1": 850, "y1": 40, "x2": 980, "y2": 200},
    "weapon": {"x1": 30, "y1": 850, "x2": 180, "y2": 990},
    "merchant": {"x1": 350, "y1": 180, "x2": 700, "y2": 550},
}

# Расчёт позиции ячейки
func get_cell_position(zone: Dictionary, row: int, col: int) -> Vector2:
    var cell_w = (zone.x2 - zone.x1) / zone.cols
    var cell_h = (zone.y2 - zone.y1) / zone.rows
    return Vector2(zone.x1 + col * cell_w, zone.y1 + row * cell_h)
```

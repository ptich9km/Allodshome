# Blacksmith UI — Allodshome

Интерфейс кузницы (переплавка предметов в слитки). Фоновое изображение — `blacksmith.jpeg` (1024×1024).

---

## Зоны интерфейса

Все координаты в пикселях относительно изображения 1024×1024.

### Панели кузницы

| Зона | Координаты | Ячейки | Размер ячейки | Назначение |
|------|-----------|--------|---------------|------------|
| **BLACKSMITH_OUTPUT** | (46, 210) — (218, 853) | 7×1 = 7 | 172×92 | Что кузнец выплавил (левая панель). Сюда попадают слитки после переплавки. |
| **PLAYER_INVENTORY** | (265, 789) — (1006, 1018) | 2×6 = 12 | 124×114 | Инвентарь игрока (нижняя панель). Предметы, которые можно отдать на переплавку. |

---

## Логика работы кузницы

1. **Открытие кузницы:** игрок кликает на строение кузница → открывается UI с `blacksmith.jpeg` как фон.
2. **PLAYER_INVENTORY:** отображает вещи игрока (оружие/броня). Игрок выбирает предмет → предмет отправляется на переплавку.
3. **BLACKSMITH_OUTPUT:** отображает результат переплавки (слитки). Игрок забирает слитки → слитки переходят в инвентарь игрока.
4. **Переплавка:** предмет из PLAYER_INVENTORY → кузнец переплавляет → слиток появляется в BLACKSMITH_OUTPUT.

## Использование в Godot

```gdscript
# Загрузка фона кузницы
var blacksmith_bg = load("res://assets/blacksmith/blacksmith.jpeg")

# Координаты зон
const ZONES = {
    "blacksmith_output": {"x1": 46, "y1": 210, "x2": 218, "y2": 853, "rows": 7, "cols": 1},
    "player_inventory": {"x1": 265, "y1": 789, "x2": 1006, "y2": 1018, "rows": 2, "cols": 6},
}

# Расчёт позиции ячейки
func get_cell_position(zone: Dictionary, row: int, col: int) -> Vector2:
    var cell_w = (zone.x2 - zone.x1) / zone.cols
    var cell_h = (zone.y2 - zone.y1) / zone.rows
    return Vector2(zone.x1 + col * cell_w, zone.y1 + row * cell_h)
```
